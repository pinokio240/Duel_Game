# DUEL — танковая дуэль

Неоновая аркадная дуэль 1 на 1: вы против бота. Соберите свой танк из шасси и
корпуса, переживите 5 раундов и заберите матч. Написано на Python + Pygame,
звуки генерируются кодом — никаких файлов ресурсов.

![Скриншот боя](screenshot.png)

## Как запустить на Windows 10

1. Установите Python 3.10+ с [python.org](https://www.python.org/downloads/)
   — при установке обязательно поставьте галочку **Add Python to PATH**.
2. Скачайте этот репозиторий: зелёная кнопка **Code → Download ZIP**, распакуйте.
   (Или через git: `git clone https://github.com/pinokio240/Duel_Game.git`)
3. Откройте командную строку в папке проекта и выполните:

```bat
pip install -r requirements.txt
python main.py
```

## Управление

| Клавиша | Действие |
|---------|----------|
| W / S   | вперёд / назад |
| A / D   | поворот влево / вправо |
| Пробел  | выстрел |
| Esc     | пауза |

В ангаре: **A/D** — выбрать шасси, **W/S** — выбрать корпус, **Enter** — в бой.

## Собери свой танк

Перед боем выбираются две детали. У танка нет «имба»-сборки — у всего своя цена.

### Шасси — определяет скорость и поворот

| Шасси | Скорость | Поворот | Бонус |
|-------|----------|---------|-------|
| Лёгкое  | 220 px/с | 250 гр/с | — |
| Среднее | 175 px/с | 200 гр/с | броня 6 |
| Тяжёлое | 125 px/с | 155 гр/с | броня 12 |

### Корпус — определяет прочность (HP) и вес

| Корпус | HP | Вес (замедление) | Перезарядка |
|--------|----|------------------|-------------|
| Лёгкий  | 70  | 0%  | 0.55 с |
| Средний | 110 | 15% | 0.70 с |
| Тяжёлый | 160 | 35% | 0.85 с |

**Закон баланса:** итоговая скорость = скорость шасси × (1 − вес корпуса).
Хотите тяжёлое шасси + тяжёлый корпус? Пожалуйста: 160 HP и броня 12,
но ехать вы будете со скоростью 81 px/с — медленнее всех в игре.
Наглеть нельзя: броня = медлительность, скорость = хрупкость.

Снаряды наносят 30 урона, броня снижает урон, но не меньше 5 за попадание.

## Бонусы в бою

Бонусы появляются на арене каждые ~8 секунд (не больше 3 сразу):

| Знак | Бонус | Эффект |
|------|-------|--------|
| Щ (синий) | Щит | получаемый урон ×0.4 на 5 сек |
| В (жёлтый) | Веер | 3 выстрела тройной очередью |
| У (зелёный) | Турбо | +60% скорости на 4 сек |
| + (красный) | Ремонт | +40 к прочности |

## Снаряды и рикошеты

Снаряд один раз рикошетит от стен и препятствий — можно стрелять «из-за угла».
От своего же снаряда в первые мгновения вы защищены, но вернувшийся рикошетом
снаряд может ударить и по вам.

## Матч

- Матч = раунды до **5 побед**.
- После каждого раунда танки восстанавливаются, бонусы появляются заново.
- Бот каждый матч получает **случайную сборку** — смотрите в HUD, кто к вам приехал.

## Настройка баланса

Все цифры вынесены в `settings.py` — скорость, урон, HP, бонусы, палитра.
Меняйте и экспериментируйте, код трогать не нужно.

## Структура проекта

```
main.py        — точка входа
settings.py    — весь баланс и настройки (начните изучение с него)
game.py        — состояния игры: меню, ангар, раунды, HUD
tank.py        — танк: движение, стрельба, броня, бонусы
bullet.py      — снаряды и рикошеты
bot.py         — ИИ бота (дистанция, уклонения, добивание бонусов)
arena.py       — арена, стены, коллизии, линия видимости
powerup.py     — бонусы
effects.py     — частицы, взрывы, тряска камеры
sound.py       — звуки, синтезируемые numpy
```
